# Verity — AI Content Review Studio
Verity is a content review tool designed to help users identify potential issues in written content before publication.

The concept focuses on reviewing written content for repetition, structural issues, and unsupported claims, helping writers and editors examine their work before publishing.

## Features
- Create and edit written content.
- Save drafts and return to them later.
- Run content analysis.
- View reports organized into three review categories.
- Edit content after reviewing a report.
- Access previously saved documents and their reports.
- Store documents in the browser using local storage, so they remain available after refreshing the page.

## Review Categories
The application currently displays three predefined categories:
- Repetition
- Structural Issues
- Unsupported Claims

At this stage, these are default sections in the analysis report. The application does not yet identify specific sentences or passages containing these issues, or explain why particular parts of the submitted content may need attention.

The intended concept is for each category to contain relevant findings based on the submitted text, rather than simply displaying the category names.

## Current Limitations
The current analysis uses basic, predefined JavaScript rules. It does not understand the context or meaning of different texts, so its findings are limited and may not accurately reflect the content being reviewed.

Achieving the intended analysis would require more advanced techniques, such as Natural Language Processing (NLP) and AI integration.

## Technologies
